# Mapping verification

Research checked on 2026-10-16. It verifies the `osm` and `schema_org` mappings in `schema/site-types.json` and `schema/facilities.json` against primary sources. Corrections are applied in those files and in `schema/mappings/osm.md` and `schema/mappings/schema-org.md`.

## Sources and method

- OSM wiki pages, read as wikitext through `?action=raw` so the `status` field of each Map Features template is quoted exactly: https://wiki.openstreetmap.org/wiki/Map_Features and the Tag: and Key: pages linked in the tables.
- taginfo usage counts, from https://taginfo.openstreetmap.org/api/4/tag/stats and /key/stats, data current to 2026-10-13. The counts are worldwide and count nodes, ways and relations together. taginfo has no per-country filter, so Australian relevance rests on the Australian tagging guidelines page (https://wiki.openstreetmap.org/wiki/Australian_Tagging_Guidelines/Roads) and on Australian names in taginfo values.
- schema.org types and properties, checked against the current vocabulary file (https://schema.org/version/latest/schemaorg-current-https.jsonld) for existence, parent types and the `domainIncludes` of each property, with the page for each term linked in the tables.
- OSM status values used: approved (passed the proposal process), de facto (widely used without a vote), in use (documented from use, no process), deprecated or discouraged (none found among the tags checked).

## Findings that changed the lists

1. **Showground has an in-use tag.** `landuse=recreation_ground` with `recreation_ground=showground` is documented at https://wiki.openstreetmap.org/wiki/Tag:recreation_ground=showground (status in use, 263 uses). The earlier note that OSM has no showground tag was wrong. The mapping is narrower than the OTWD entry because it does not cover racecourses.
2. **`shower=hot` is a tagging mistake.** Key:shower lists `shower=yes` and `shower=no`, and Key:hot_water lists `shower=hot` as a possible synonym error. The showers mapping now uses `hot_water=yes`.
3. **`fireplace=yes` is for chimneys.** Key:fireplace says open fire pits use `firepit=yes` or `leisure=firepit`. The fire pit mapping now uses `firepit=yes`.
4. **Toilet disposal values.** The documented values are `flush`, `pitlatrine`, `chemical`, `bucket`, `dry_toilet`, `tank` and `incineration` (Tag:amenity=toilets). The old mapping carried one value and a note naming two others. It now has one row per value, and the pit kind maps to `pitlatrine`.
5. **Swimming spot.** `leisure=swimming_area` is for a marked area within water (area only, status de facto), so it is narrower than the entry, not exact. `leisure=bathing_place` (in use) describes wild swimming spots and is added.
6. **Bins, picnic tables, dogs, rig limits, information centres and rest areas** gained documented keys (`bin=yes`, `picnic_table=yes`, `dog=unleashed`, `maxheight=*`, `maxweight=*`, `information=visitor_centre`, and `tourism=camp_site` with `maxstay=*` for camping at a rest area).
7. **schema.org.** The mappings page said `RVPark` inherits `petsAllowed` from `LodgingBusiness`. In the current vocabulary `RVPark` is a `CivicStructure` only, so `petsAllowed` applies to `Campground` but not `RVPark`. Notes were also corrected for `Hospital` (it is itself an `EmergencyService`) and `swimming_spot` (`PublicSwimmingPool` exists).

## Items with no good OSM tag

These keep an empty `osm` list. The vocabulary schema allows an empty list for osm and null for schema_org, and neither form has a `note` field, so the reasons are recorded here instead of in the lists.

- **mobile_coverage:** no tag. `mobile_coverage` has 0 uses and `communication:mobile_phone` marks tower equipment.
- **generators_allowed, ensuite_sites, drive_through_sites:** no documented tag for camp sites. `drive_through` is for amenities that serve vehicles.

## Open points for the maintainers

- The example in `schema/mappings/schema-org.md` puts `petsAllowed`, `checkinTime` and `checkoutTime` on an `RVPark`. In schema.org these properties are defined for `LodgingBusiness` (and `Accommodation` for pets), which `RVPark` is not. Using `Campground` in the example, or accepting the looser use, is a decision for the maintainers, so the example was not changed.
- Rest areas: the Australian guidelines say camping at a rest area is also tagged `tourism=camp_site`. That row is related, not exact, because OTWD records overnight rules in `stay_limits`.
