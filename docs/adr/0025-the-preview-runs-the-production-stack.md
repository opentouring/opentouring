# The preview runs the production stack

The concept build shown to a prospective host runs the real production stack at minimum size, with public code from day one, rather than a prototype. The public Preview site carries seeded government data and only the maintainer's own submissions. Outside contributions are switched off, and FuelOracle's contribute-back runs in staging only until a host exists. A host is being asked to take on assets, so the assets must be real: a working platform shows what it costs to run and that it can be handed over.

## Consequences

Running costs start before any revenue. Everything that would block a handover (accounts, secrets, domains) is set up from the start to be transferable.
