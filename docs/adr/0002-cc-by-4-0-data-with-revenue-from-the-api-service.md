# CC BY 4.0 data, with revenue from the API service

OTWD data is published under CC BY 4.0. Open Touring earns its running costs from the paid API service (volume, service level, change feeds and their webhooks, delta files, support) and from sponsors, never from selling or licensing the data itself. Attribution-only data is what councils, park agencies and app developers can use without legal review, and it lets contributors see that their work stays open. Obligations such as contributing corrections back belong in the API terms of service, which are a contract, because CC 4.0 licences forbid adding extra terms to the licence itself.

## Considered options

- **ODbL.** Rejected: share-alike on a database is hard for partner apps to reason about, and it would not stop a dual-licensing problem later. It also gives no revenue path, because ODbL data cannot be sold under a different licence.
- **CC BY-NC-SA for free use plus a paid commercial licence.** Rejected: "non-commercial" is vague, excludes most of the contributors and partner apps the dataset needs, and dual licensing crowd data only works if every contributor has granted relicensing rights first.
- **CC0.** Rejected: attribution is how seed sources and contributors get credit, and some government seed sources require it.

## Consequences

Australian law gives factual compilations little or no copyright protection and has no database right, so the project's protection comes from the API key and its terms of service, not from the licence. Paid tiers sell service, never a different licence and never a different moderation standard: "priority moderation" means faster turnaround only.
