# No OpenStreetMap data import

OTWD never imports data from OpenStreetMap. OSM data is licensed under the ODbL, and a database that contains it must itself stay under the ODbL, which conflicts with publishing OTWD under CC BY 4.0 and with the contributor grant. Seed data comes from government open data under compatible licences and from councils, tourism bodies and park agencies releasing data under CC BY.

## Consequences

Contributors and moderators must not copy from OSM, just as they must not copy from WikiCamps, Google or guidebooks, and the contributor terms say so. OTWD still publishes mappings to OSM tags so others can compare or combine the datasets on their side. Showing an OSM-based basemap on the Open Touring website is allowed, because a rendered map is a produced work that needs attribution only and puts no OSM data into OTWD.
