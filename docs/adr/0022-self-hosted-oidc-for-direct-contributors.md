# Self-hosted OIDC for direct contributors

Direct contributors and moderators sign in through a self-hosted OIDC provider, Zitadel or Keycloak, running in the cluster. Contributor identities are personal data that the host must control and be able to move, which a hosted identity service with per-user pricing does not allow. The choice between Zitadel and Keycloak is still open, so this stays proposed.
