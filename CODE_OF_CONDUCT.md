# Code of conduct

Open Touring adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in every project space (the repository, issues, pull requests, discussion forums and events) and when someone represents the project in public.

## Reporting

Report behaviour that breaks the code of conduct to conduct@opentouring.org. Reports are read by the maintainer and, once it exists, the steering group. Reports are handled in confidence, and anyone named in a report is excluded from handling it.

## Enforcement

Enforcement follows the Contributor Covenant 2.1 enforcement guidelines: correction, warning, temporary ban and permanent ban.
